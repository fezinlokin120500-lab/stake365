STAKE365 social casino-style website preview

Open index.html in a modern browser. It includes:
- Stake-inspired dark/green casino layout
- R$ 200 starting play-credit balance
- Add play credits (custom amount)
- Eight selectable game tiles
- A demo betting panel with 60% simulated win chance
- Friends panel, invite link and recent rounds

This is a front-end prototype only. Balances are play credits with no cash value.
No real deposits, withdrawals, prizes, user accounts, multiplayer synchronization or server backend.

To deploy: create a GitHub repository with index.html, then create a Render Static Site
from that repository. Use the repository root as the publish directory. Render will assign
an onrender.com hostname; the exact stake365.onrender.com name depends on availability.
